# 模型假设与适用范围

这份文档把两个模型里**每一个可以被质疑的地方**都摊开写清楚。理由很实际：地理类 AI 项目翻车，几乎都翻在「把演示当预测」上。与其等评委问，不如自己先写明。

---

## 一、坡面水土流失（RUSLE）

### 1.1 基本结构

```
A = R · K · LS · C · P
```

- `A`：多年平均年土壤流失量，单位 t/(ha·a)
- `R`：降雨侵蚀力，MJ·mm/(ha·h·a)
- `K`：土壤可蚀性，t·h/(MJ·mm)
- `LS`：坡度坡长因子，无量纲
- `C`：覆盖管理因子，无量纲，0–1
- `P`：水土保持措施因子，无量纲，0–1

量纲自洽：`R·K` 的单位是 `t/(ha·a)`，其余三项无量纲。代码中有对应的一致性测试（`test_soil.py::test_identity`），确保实现里没有偷偷加修正项。

### 1.2 坡度因子 S

```
S = 10.8·sinθ + 0.03            tanθ < 0.5   (θ < 26.6°)
S = 16.8·sinθ − 0.50            tanθ ≥ 0.5
```

**出处**：McCool et al. (1987) 缓坡式；Nearing (1997) 陡坡修正式。
**分界点**：`tanθ = 0.5` 即 26.6°，这是文献给出的适用分界，不是随意取的。
**已知偏差点**：26.6° 附近两式并不严格连续（约差 0.1–0.2），本项目沿用文献原式的分段做法，不做平滑——因为平滑会引入没有出处的修正。

### 1.3 坡长因子 L

```
L = (λ / 22.13)^m
m = β / (1 + β)
β = (sinθ / 0.0896) / (3·sin^0.8θ + 0.56)
```

**出处**：Renard et al. (1997)，USDA Agriculture Handbook 703。
**常数 22.13**：标准小区的坡长 22.13 m，是 RUSLE 的定义基准，不是拟合参数。
**m 的性质**：`m ∈ (0,1)` 恒成立，因此坡长与流失量是**次线性**关系——坡长翻倍，流失量不会翻倍。这一点在教学上很重要，学生普遍以为是线性的。

### 1.4 覆盖管理因子 C —— 本模型最需要被质疑的地方

有两种输入方式：

**方式一：直接给定（推荐用于真实研究）**

```
cover_factor = 0.15      # 来自当地实测或文献
```

这是**唯一科学严谨**的用法。C 因子的标准获取方式是按作物轮作、耕作方式、覆盖度查表或实测。

**方式二：由覆盖度换算（教学用）**

```
C = exp(−decay × 覆盖度%)
decay 默认 0.04
```

性质：`C(0%) = 1`、`C(50%) ≈ 0.135`、`C(80%) ≈ 0.041`、`C(100%) ≈ 0.018`。单调递减、量级接近文献中草地与林地的 C 值范围。

**必须承认的三点**：

1. `decay = 0.04` 不是一个有严格出处的普适常数。它被选在这里，是因为能让曲线量级落在合理区间，便于教学演示。
2. 改用 `decay = 0.06` 时，60% 覆盖的 C 会从 0.091 降到 0.027，流失量直接降为约 1/3。**这个参数的影响比任何其他参数都大**，所以它在 UI 里是显式可调的，而不是藏在代码里。
3. 真实 C 因子还取决于**覆盖的空间连续性、枯落物厚度、地面残茬、季节性**，单一覆盖度百分比不足以刻画。

因此：**用方式二做出来的绝对数值不可引用**，只能看趋势与相对变化。README 与技能文档里都写死了这一条。

### 1.5 措施因子 P

| 措施 | P（本模型取中值） | 文献常见范围 |
|---|---|---|
| 无措施（顺坡耕作） | 1.00 | 1.00 |
| 等高耕作 | 0.55 | 0.50–0.60 |
| 等高带状间作 | 0.35 | 0.25–0.45 |
| 梯田 | 0.20 | 0.10–0.30 |
| 退耕还林还草 | 0.05 | 0.01–0.10 |

P 值与**坡度、坡长、措施质量、维护年限**强相关。本模型取单一中值，因此「梯田减 80%」这个结论只在"梯田质量合格且维护良好"的前提下成立。

### 1.6 侵蚀强度分级

按《土壤侵蚀分类分级标准》SL 190-2007，水力侵蚀（t/(ha·a)）：

| 等级 | 阈值 |
|---|---|
| 微度 | < 2 |
| 轻度 | 2 – 5 |
| 中度 | 5 – 10 |
| 强烈 | 10 – 20 |
| 极强烈 | 20 – 40 |
| 剧烈 | > 40 |

注意该标准还区分**南方红壤丘陵区**与**北方土石山区**等类型区，阈值有所不同。本项目采用通用阈值，未做分区。

### 1.7 明确不模拟的东西

- 细沟与切沟的发育过程
- 坡面汇流路径与泥沙沿程沉积（RUSLE 是**产沙**模型，不是**输沙**模型）
- 场次暴雨事件（只有年尺度平均值）
- 冻融、风蚀、重力侵蚀
- 土地利用变化的时间序列

### 1.8 典型参数的量级参考

| 参数 | 半湿润区 | 湿润区（长江中下游等） |
|---|---|---|
| R | 1000–2500 | 4000–8000 |
| K（壤土） | 0.04–0.05 | 0.03–0.05 |
| K（砂土） | 0.02–0.03 | 0.02–0.03 |
| K（黏土） | 0.015–0.025 | 0.015–0.025 |

**这些是数量级参考，不是可以直接引用的区域参数。** 真实研究必须用当地气象站计算的 R 与实测的 K。

## 二、弯曲河道侵蚀与沉积倾向

### 2.1 模型的本质

这是一个**规则化模型**：把"凹岸冲刷、凸岸淤积"这一成熟定性认识，写成可参数化、可重复计算的形式。它不解方程，只是把一个物理图像翻译成公式。

**它输出的不是冲淤量，是冲淤倾向。**

### 2.2 横向流速剖面

```
v/v̄ = 1 + A(φ)·(2s − 1)
```

- `s ∈ [0,1]`：横向位置，0 为凸岸（内侧），1 为凹岸（外侧）
- `φ`：沿弯道的相对位置
- 因 `(2s−1)` 在 [0,1] 上积分为 0，所以**断面平均流速严格守恒**，这是模型自洽性的一个硬约束，有对应测试

### 2.3 环流幅度

```
A0 = clamp(0.15 + 0.5/(Rc/B), 0.05, 0.50)
```

`Rc/B` 是弯道半径比，越小表示弯越急。A0 随 `Rc/B` 单调下降，上下界保证外推到极端几何时不出非物理值。

**依据**：弯道横向环流强度随曲率增大而增强，这是弯道水力学的基本结论。具体的函数形式与系数是本项目的工程近似，**没有逐点实验标定**。

### 2.4 沿程包络

```
A(φ) = A0 · sin(π · t^1.4),    t = φ/φ_max
```

峰值落在 `t ≈ 0.61`，即**弯顶偏下游**。

**依据**：横向环流需要沿程距离才能充分发展，最大冲刷坑通常出现在弯顶下游而不是弯顶正上方，这是弯道观测中的常见认识。

**局限**：指数 1.4 是拟合出来的形状参数，用来把峰值放在约 60% 处，没有实测数据支撑其精确值。

### 2.5 床面剪应力

```
τ = ρ · (f/8) · v²,    ρ = 1000 kg/m³
```

- `f`：达西—魏斯巴赫阻力系数，默认 0.03
- 这是**一维量级估算**，不是二维流场求解
- `τ ∝ v²` 是模型的硬性质，有对应测试（流速翻倍，剪应力必须变 4 倍）

### 2.6 起动条件与冲淤判据

模型把两件事分开处理，这是设计上的刻意选择：

**动力学判据**：`τ/τc`，`τc` 由岸坡材质给定

| 材质 | τc (Pa) | 说明 |
|---|---|---|
| 松散砂质岸 | 2 | 极易冲刷 |
| 粉砂/壤土岸 | 8 | 中等抗冲 |
| 黏性土岸 | 20 | 抗冲较强，但干湿交替易崩岸 |
| 基岩或硬护岸 | 80 | 基本不冲刷 |

**运动学判据**：`v/v̄` 偏离 1 的方向与幅度

| 相对流速 | 倾向 |
|---|---|
| v/v̄ ≤ 0.825 | 强沉积 |
| 0.825 < v/v̄ ≤ 0.95 | 沉积 |
| 0.95 < v/v̄ ≤ 1.05 | 冲淤平衡 |
| 1.05 < v/v̄ ≤ 1.175 | 侵蚀 |
| v/v̄ > 1.175 | 强侵蚀 |

**为什么要分开**：凹岸流速大是运动学结论，但流速大不等于能冲起来。黏性土岸在同样的水流下可能根本不发生冲刷。把两者混成一个指数，学生会误以为"流速大 = 一定冲"。所以结果里 `stress_exceed_ratio` 与 `tendency` 并列呈现，解释时必须同时提到。

### 2.7 明确不模拟的东西

- 泥沙输移率与河床变形（不含 Exner 方程）
- 二维流场（不含 N-S 或浅水方程求解）
- 分汊河段、游荡型河段、河口潮汐河段、水库回水段
- 崩岸机制（土体力学、含水率、根系）
- 上游来沙条件与床沙级配的影响
- 冲淤厚度、体积、时间尺度

### 2.8 可以怎么用它

✅ 讲清「为什么会凹岸冲、凸岸淤」
✅ 对比「弯道变急 / 流速变大 / 护岸变硬」时冲淤格局的方向性变化
✅ 训练学生区分「运动学倾向」与「动力学能否发生」

❌ 预测某条真实河流某一年会冲多深
❌ 航道淤积计算、护岸设计
❌ 作为任何工程或规划的依据

## 三、跨模块的边界

当学生问「坡面泥沙与河流沉积的关系」时，两个模型**不能数值拼接**：

| | 坡面水土流失模型 | 弯道模型 |
|---|---|---|
| 输出量 | 年流失量 t/(ha·a) | 剪应力 Pa、倾向分类 |
| 时间尺度 | 多年平均 | 瞬时断面状态 |
| 空间尺度 | 坡面小区 | 河道断面 |
| 是否含输移 | 否（产沙） | 否（只判倾向） |

从"坡面产沙"到"河道沉积"之间，还需要**泥沙输移比（SDR）、沿程滞留、粒径分选、来沙与挟沙力对比**等本课程范围外的参数。因此系统只做概念串联，不生成合并数值——`router.py` 里的 `cross_module` 分支会显式返回这条说明。

## 四、如果要做真实研究，应该怎么改进

1. **R 与 K 换成区域实测值**，不要用默认值。
2. **C 因子改用当地实测或查表值**，通过 `cover_factor` 直接输入，不要用指数映射。
3. **坡度坡长做分段计算**，把复杂坡面按坡度变化切成若干段，分别算 LS 再加权汇总。
4. **弯道部分改用二维水沙模型**（如 Delft3D、MIKE 21C 或 TELEMAC-2D），本模型只作为教学前导或结果对照。
5. **做敏感性分析**，确认结论对 `cover_decay`、`A0` 系数等经验参数的依赖程度——`analyze` 模式已经为此提供了工具。
