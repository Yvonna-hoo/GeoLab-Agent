# 弯曲河道侵蚀与沉积倾向

## 何时使用

学生的问题涉及「河道哪一侧会冲、哪一侧会淤」「弯道形态改变会怎样」时使用。典型问法：

- 「弯曲河道的哪些部位更容易被侵蚀？」
- 「为什么凹岸陡、凸岸有沙滩？」
- 「河道变得更弯，冲刷会加剧吗？」

若问题涉及坡面来沙，见跨模块处理——**不要把本工具的输出与水土流失工具的输出拼成一个数**。

## 工具

工具名：`geolab_river_bend`

```json
{
  "mode": "run | sweep | compare | analyze",
  "params": {
    "bend_radius_m": 150,
    "channel_width_m": 60,
    "mean_velocity_ms": 1.2,
    "depth_m": 3.0,
    "bend_angle_deg": 90,
    "roughness_f": 0.03,
    "bank_material": "silt_loam"
  },
  "sweep": { "parameter": "bend_radius_m", "values": [40,60,90,120,150,200,300,500,800] }
}
```

| 参数 | 单位 | 允许范围 | 说明 |
|---|---|---|---|
| `bend_radius_m` | m | 20–2000 | 中心线曲率半径，越小弯越急 |
| `channel_width_m` | m | 5–500 | 弯道处水面宽 |
| `mean_velocity_ms` | m/s | 0.2–5 | 断面平均流速 |
| `depth_m` | m | 0.5–15 | 平均水深 |
| `bend_angle_deg` | ° | 15–270 | 进口到出口的中心线转角 |
| `roughness_f` | — | 0.02–0.08 | 达西阻力系数，沙质河床常见 0.02–0.04 |
| `bank_material` | — | 枚举 | `loose_sand`(τc≈2Pa) / `silt_loam`(8) / `cohesive_clay`(20) / `rock_revetment`(80) |

## 返回值怎么读

| 字段 | 含义 |
|---|---|
| `rc_over_b` | 弯道半径比，控制环流强弱的关键无量纲量 |
| `circulation_amplitude` | 横向流速偏离幅度 A0（无量纲） |
| `tau_max_pa` | 最大床面剪应力（Pa） |
| `bank_tau_c_pa` | 该岸坡材质的起动剪应力（Pa） |
| `stress_exceed_ratio` | τmax/τc，**>1 才意味着真的能冲起来** |
| `field[][]` | 二维冲淤场，行=沿程，列=横向（0=凸岸，末位=凹岸） |
| `tendency` | 强侵蚀 / 侵蚀 / 冲淤平衡 / 沉积 / 强沉积 |

## 必须遵守的解释纪律

1. **分清"流速偏向"和"真的冲刷"**。凹岸流速大是运动学结论；能不能冲起来要看 `stress_exceed_ratio`。当它小于 1 时必须说：「流速虽偏向凹岸，但剪应力没有超过该材质的起动条件，未必形成明显冲刷。」
2. **本模型不算冲淤量**，只给倾向分区。不能说"这里会冲深 2 米"。
3. **必须声明这是概念演示**：
   > 这是规则化的教学模型，不是二维水沙数值模型，不能预测真实河床演变。
4. **不要说"预测"**。可以说"在给定条件下，模型显示……"。
5. **横向环流是机理核心**：凹凸岸的差异来自弯道离心力引起的横向环流——表层水流冲向凹岸、底层水流携沙流向凸岸，所以凹岸冲、凸岸淤。解释时要讲这条因果链，而不是只报数字。

## 出错时怎么办

同水土流失工具：读 `errors[]` 的 `field` / `code` / `allowed`，改对再试，不要绕过。

## 常见的教学追问与正确回答方式

**问：为什么最大冲刷不在弯顶正中间？**
答：横向环流需要一段距离才能充分发展，最大冲刷通常出现在弯顶**偏下游**。本模型用沿程包络 sin(π·t^1.4) 表达了这一形态，峰值在沿程约 60% 处。

**问：为什么弯道半径变小，冲刷反而增强？**
答：Rc/B 越小，离心作用与横向环流越强，主流更偏向凹岸，凹岸剪应力随之升高。可让学生自己用 `sweep` 扫一遍 `bend_radius_m` 验证。

**问：为什么砂岸和岩岸的剪应力一样，结论却不同？**
答：水流条件相同，所以 τ 相同；差别在起动剪应力 τc。砂岸 τc≈2 Pa，很容易被冲；硬护岸 τc≈80 Pa，同样的水流冲不动。这正好说明「地貌演变 = 动力 × 抗性」两个因素共同决定。

**问：凸岸为什么会形成边滩？**
答：内侧流速低、剪应力小，挟沙能力下降，泥沙在此落淤，长期堆积成边滩（点坝），也是河流地貌中"凸岸堆积、凹岸侵蚀、河道向凹岸侧移"的来源。

## 禁止事项

- 不要用它预测真实河床演变、航道淤积或护岸工程设计。
- 不要外推到分汊河段、游荡型河段、河口潮汐段与水库回水段。
- 不要给出冲淤厚度或体积等本模型未计算的量。
