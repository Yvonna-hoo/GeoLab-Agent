# 坡面水土流失实验（RUSLE）

## 何时使用

学生的问题涉及「坡面土壤流失量的多少、变化方向、措施效果」时使用本技能。典型问法：

- 「植被覆盖变化怎样影响土壤流失？」
- 「坡度从 5% 加到 20%，流失量会翻几倍？」
- 「改成梯田能减少多少流失？」
- 「这块地算不算严重的水土流失？」

若问题同时涉及河道搬运与沉积，**不要**只用本技能给结论，参见跨模块处理。

## 工具

工具名：`geolab_soil_erosion`

```json
{
  "mode": "run | sweep | compare | analyze",
  "params": {
    "rainfall_erosivity": 4500,
    "soil_erodibility": 0.030,
    "slope_percent": 8,
    "slope_length_m": 30,
    "vegetation_cover_pct": 60,
    "cover_decay": 0.04,
    "cover_factor": null,
    "practice": "none"
  },
  "sweep": { "parameter": "vegetation_cover_pct", "values": [0,20,40,60,80,100] },
  "compare": { "baseline_label": "基准组", "variants": [{"label": "梯田", "params": {"practice": "terracing"}}] },
  "analyze": { "outputs": ["soil_loss_t_ha_yr"] }
}
```

字段说明：

| 参数 | 单位 | 允许范围 | 说明 |
|---|---|---|---|
| `rainfall_erosivity` | MJ·mm/(ha·h·a) | 100–20000 | 半湿润区约 1000–2500，湿润区约 4000–8000 |
| `soil_erodibility` | t·h/(MJ·mm) | 0.005–0.08 | 砂土≈0.02–0.03，壤土≈0.04–0.05 |
| `slope_percent` | % | 0–60 | 8% ≈ 4.6° |
| `slope_length_m` | m | 1–500 | 坡面水平投影长度 |
| `vegetation_cover_pct` | % | 0–100 | 冠层＋枯落物覆盖比例 |
| `cover_decay` | 1/% | 0.01–0.15 | C = exp(-decay × 覆盖度%) 的系数 |
| `cover_factor` | — | 0.001–1 | 直接给定 C，给定时覆盖上一项 |
| `practice` | — | 枚举 | `none` / `contour_tillage` / `contour_strip` / `terracing` / `reforestation` |

## 四种模式怎么选

| 学生的问题形态 | 用哪个模式 |
|---|---|
| 「大概多少」 | `run` |
| 「变化会怎样」「随……怎么变」 | `sweep` |
| 「改措施能减多少」「哪个更好」 | `compare` |
| 「哪个因子影响最大」 | `analyze` |

## 必须遵守的解释纪律

1. **只解释工具返回的数值**，不要自己心算或复述一个"差不多"的数。结果的 `outputs` 里已经有 `headline`、`factors`、`intensity_class`，直接引用。
2. **必须同时给出边界**。每次回答都要带一句适用范围，例如：
   > 这是多年平均的示例估算，不是实测输沙量，也不能用于工程设计；单次暴雨的侵蚀量会明显偏离这个平均值。
3. **单位不能省**：`t/(ha·a)`，不要说成「吨」或「吨每平方公里」。
4. **侵蚀等级**按 SL 190-2007 水力侵蚀分级：微度<2、轻度2–5、中度5–10、强烈10–20、极强烈20–40、剧烈>40，单位 t/(ha·a)。等级由工具给，不要自己判。
5. **区分「模拟」与「预测」**：本工具是教学估算，绝不能说"预测明年这块地会流失多少吨"。

## 出错时怎么办

工具返回 `ok: false` 时，`errors[]` 里每条都有 `field`、`code`、`message`、`allowed`。

- `above_max` / `below_min`：把值改到 `allowed` 范围内再重试，并**告诉学生原来那个值为什么不合理**（例如覆盖度不可能大于 100%）。
- `unknown_parameter`：参数名拼错了，从 `allowed` 里选。
- `bad_choice`：枚举值不在允许列表里。

不要绕过校验，不要自己编一个结果顶上。

## 常见的教学追问与正确回答方式

**问：为什么覆盖度从 60% 提到 80%，流失量降了一半多？**
答：因为 C 因子按指数衰减，覆盖度越高，边际效果越明显——这正是"植被恢复要连片、要形成郁闭"的数学表达。但要提醒：这个指数关系是本模型的简化假设，`cover_decay` 一改，结论的量级就变，所以真实坡面必须用当地实测 C 因子替换（通过 `cover_factor` 直接输入）。

**问：为什么坡长翻倍，流失量没有翻倍？**
答：因为 L = (λ/22.13)^m，m 由坡度决定且恒小于 1，所以坡长与流失量是次线性的关系。

**问：梯田为什么能减 80%？**
答：P 从 1.0 降到 0.20，A 与 P 成正比，所以减 80%。要补充：这是把坡面截短、拦截泥沙的工程效果，实际效果取决于梯田质量与维护。

## 禁止事项

- 不要声称该工具的计算结果可用于水土保持工程设计、环境影响评价或政策制定。
- 不要把 RUSLE 说成能模拟细沟、切沟或泥沙输移。
- 不要在学生未给参数时，凭空编造"当地典型值"而不标注这是默认值。
